# Ереван: куда сегодня

Личный гид по Еревану: куда сходить после работы и куда поехать в выходной с утра, чтобы к ночи быть дома.

- «Сейчас»: рекомендации с учётом геопозиции, часов работы, заката, погоды (Open-Meteo) и пути домой.
- «План»: вечер или день по шагам, время в пути и «успеваем или нет».
- «Маршруты», «Афиша», «Места» с фото, отзывами и лучшим временем для визита.
- Ставится на телефон как приложение (PWA), работает офлайн.

Статический сайт без сборки: `index.html`, `js/data.js` (места и маршруты), `js/app.js`, `data/events.json` (афиша).

Обновить афишу: `python3 scripts/dump_afisha.py` выгружает посты из локальной базы tg-armenia, по ним собирается `data/events.json`.
